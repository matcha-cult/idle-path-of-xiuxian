- **认证**：注册/登录/JWT，bcrypt 哈希

- **接口**：NestJS HTTP REST（`POST /api/auth/register`、`POST /api/auth/login`、`GET /api/character/check`、`POST /api/character/create`、`GET /api/character/info`）
- **WS 入口**：`/ws-user`（仅连接接入，不承载业务逻辑）
- **ionet-ts**：仅注册 HealthAction，不启动 ionet HTTP/WS——满足「不调整 ionet-ts 侧 WS 接口」约束
