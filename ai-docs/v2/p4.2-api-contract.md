# P4.2 API 契约 — 离线收益

> 通用：JWT；响应 { success, message, data }；错误 data.code（HTTP 200 风格）

## 1. GET /api/game/idle/status

```json
{ "success": true, "message": "获取离线状态成功",
  "data": {
    "realm": 3,
    "lastSettleAt": "2026-09-12T08:00:00.000Z",
    "pendingHours": 2.5,
    "effectiveHours": 1.5,
    "estimatedKills": 90,
    "estimatedLingyun": 990,
    "dailyItemsProduced": 40,
    "dailyItemCap": 200,
    "config": { "roundsPerHour": 60, "efficiencyPct": 60, "maxOfflineHours": 12 }
  } }
```

## 2. POST /api/game/idle/settle

请求：`{ "unitCode": "u_r3_shigu", "hours": 12 }`
- `hours` 可选；**仅非生产环境生效**，生产环境传入 → FORBIDDEN。缺省按 `now − last_settle_at`。
- `unitCode` 必须是 hostile 单位。

```json
{ "success": true, "message": "离线结算完成：石骨傀儡 ×432",
  "data": {
    "unit": { "code": "u_r3_shigu", "name": "石骨傀儡", "realm": 3 },
    "offlineHours": 12, "effectiveHours": 7.2, "kills": 432,
    "lingyunGained": 4752, "lingyunTotal": 4752,
    "items": [ { "id": 88, "name": "精铁剑", "rarity": 2, "tier": 3, "affixTexts": ["+21 攻击"] } ],
    "kept": 12, "salvaged": { "count": 120, "lingyun": 720 },
    "sold": { "count": 0, "spiritStones": 0 }, "discarded": 0, "blockedByTier": 0,
    "currencies": { "transmute": 6 }, "essences": { "ess_atk": 2 },
    "itemsProduced": 132,
    "dailyItemsProduced": 172, "dailyItemCap": 200
  } }
```

失败码：

| code | 场景 |
| --- | --- |
| CHARACTER_NOT_FOUND | 未创建角色 |
| INVALID_PARAM | unitCode 缺失 / hours 非法（<0 或 >10000） |
| UNIT_NOT_FOUND | 单位不存在 |
| NOT_KILLABLE | 目标非敌对 |
| FORBIDDEN | 生产环境使用 hours 覆盖 |
| NOTHING_TO_SETTLE | 无（非覆盖模式下 elapsed 不足 1 杀）— 仍返回 success=true + kills=0 |
