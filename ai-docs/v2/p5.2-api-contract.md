# P5.2 API 契约 — 层深度收益 + 链式解锁

> 通用：JWT；响应 { success, message, data }；错误 data.code（HTTP 200 风格）
> 本批为 P5.1 契约的增量扩展，未列字段保持 P5.1 语义

## 1. GET /api/game/zones（新增字段）

```json
{ "success": true, "data": {
  "playerPower": 20, "currentZone": "zone_qingyun",
  "zones": [
    { "code": "zone_qingyun", "minRealm": 1, "requirePrevBestFloor": 0,
      "unlocked": true, "unlockedReason": "ok",
      "progress": { "floor": 1, "bestFloor": 0, "cleared": false } },
    { "code": "zone_miwu", "minRealm": 4, "requirePrevBestFloor": 5,
      "unlocked": false, "unlockedReason": "prev", "prevBestFloor": 0 } ] } }
```

`unlockedReason` ∈ `ok | realm | prev`。

## 2. GET /api/game/zone/progress（新增字段）

```json
{ "success": true, "data": {
  "currentZone": { "code": "zone_qingyun", "name": "青云山脚", "chapter": 1 },
  "floor": 6, "bestFloor": 5, "cleared": false,
  "playerPower": 140, "floorRequirement": 40, "canChallenge": true,
  "unlocked": true,
  "isBossFloor": false, "encounterUnit": "u_r1_shanxiao",
  "lingyunBonus": 12,
  "dropTierOffset": 1, "extraDropDraws": 1 } }
```

## 3. POST /api/game/zone/enter / challenge（新增错误码）

未解锁：

```json
{ "success": false, "message": "尚未解锁：迷雾秘境",
  "data": { "code": "ZONE_LOCKED", "reason": "prev",
    "prevZone": "zone_qingyun", "requiredPrevBestFloor": 5, "prevBestFloor": 0 } }
```

challenge 成功响应新增 `dropTierOffset`、`extraDropDraws`（见 §2 同名字段）。
