# P5.2 实施计划 — 秘境层深度收益 + 链式解锁

> 依据：v2 设计 §7.1（章节推进）、§9.1（挑战更高层秘境）；P5.1 已交付秘境与确定性层数推进
> 状态：执行中

---

## 1. 范围收敛（批决策）

| 决策 | 结论 |
| --- | --- |
| **链式解锁** | `unlocked = realm ≥ min_realm` **且** 前置秘境（order_index 前一个）`bestFloor ≥ require_prev_best_floor`；第 1 秘境无前置 |
| 解锁错误码 | 境界不足保留 `REALM_TOO_LOW`；前置未达成新增 `ZONE_LOCKED`（含 requiredPrevBest/prevBest/prevZone） |
| **层深度阶数加成** | 每 `tier_bonus_every_floors` 层，层内结算 tierOffset +1（可让深层掉出高于单位境界的底材，仍受 T14 与条目 tier 上限约束） |
| **层深度掉落加成** | 每 `drop_bonus_every_floors` 层，层内每次击杀 +1 次掉落判定 |
| **Boss 额外掉落** | Boss 层额外 +config `zoneBossExtraDraws` 次掉落判定 |
| 结算改造 | `settleKills` options 增 `tierOffsetBonus` / `dropDrawBonus`，由 zone 按层计算传入 |
| 可观测 | challenge/progress 响应暴露 `dropTierOffset`、`extraDropDraws`（确定性，便于断言） |
| 严格保底 | 本批不做（Boss 额外判定替代）；P5.3 视需要加「必掉某稀有度」 |
| 真实战斗/时长 | 顺延；战力检定维持 |

## 2. 数据变更

`game_zones` 增列（幂等 ALTER）：
```
require_prev_best_floor INT  DEFAULT 0
tier_bonus_every_floors INT  DEFAULT 0   -- 0=禁用
drop_bonus_every_floors INT  DEFAULT 0   -- 0=禁用
```

## 4. 派生公式

```
tierOffsetBonus = tier_bonus_every_floors > 0 ? floor((floor-1)/tier_bonus_every_floors) : 0
dropDrawBonus   = (drop_bonus_every_floors > 0 ? floor((floor-1)/drop_bonus_every_floors) : 0)
                + (isBossFloor ? zoneBossExtraDraws : 0)
有效 tier 上限   = unit.realm + table.tier_offset + tierOffsetBonus
每次击杀判定次数 = table.drops_per_kill + dropDrawBonus
```

## 5. API（契约详见 p5.2-api-contract.md）

- GET  /api/game/zones — zones 增加 `unlockedReason`（realm/prev/ok）、`requirePrevBestFloor`
- GET  /api/game/zone/progress — 增加 `unlocked`、`dropTierOffset`、`extraDropDraws`
- POST /api/game/zone/enter、/challenge — 未解锁时 `ZONE_LOCKED`

## 6. 冒烟清单

1. realm1：仅 zone_qingyun 解锁；zone_miwu 即使升到 4 境但前置 bestFloor<5 → ZONE_LOCKED
2. zone_qingyun 打通 5 层 → zone_miwu（达到 4 境后）解锁
3. 层深度：F1 tierOffset=0/extraDraws=0；F6 → tierOffset=1；F20 → tierOffset=3（(20-1)/5）、extraDraws=(19/3)=6
4. Boss 层（F10）→ extraDraws = 3 + zoneBossExtraDraws(2) = 5、tierOffset=(9/5)=1
5. challenge 响应暴露 dropTierOffset/extraDropDraws 与实际派生一致
6. 深层挑战产出的物品 tier 可 > 单位境界（随机验证一次，或统计 N 次出现）
7. health 200 + P5.1 冒烟关键回归

## 7. 风险 / 技术债

- 深层 tier 加成可能触及 T14 上限后失效（条目无更高 tier）→ 由 max_floor 与种子调参约束。
- 严格「必掉」保底未做；Boss 层仅额外判定。
- 链式解锁阈值（5）为拍脑袋值，待曲线验证。
