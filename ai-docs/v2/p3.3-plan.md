# P3.3 实施计划 — 古灵溶液 + 精华定向炼器

> 依据：v2 §4.6（wisp）、§5.3（精华）；批裁剪决策见 §1
> 状态：执行中

---

## 1. 批裁剪决策

| 决策 | 结论 |
| --- | --- |
| 古灵溶液 wisp | 与古灵余烬差异化：指定基底词缀替换（请求带 targetCode，仅限基底池） |
| 精华 | 最小闭环：6 种定向精华（单阶）——锋锐/蕴灵/御土/太一/回春/悟性；24 种全表与 3 合 1 升阶随 P4 掉落落地 |
| 炼丹 | 本批不做：丹药材料依赖 P4 掉落，炼丹排 P4 之后（届时丹药=物品类 flask + 丹方 seed） |

## 2. wisp 规格

- 前提：bag / 非传奇 / 非瓦尔；消耗 1 枚古灵溶液
- 请求：op=wisp + targetCode（必须存在于基底词缀池 polarity=base）
- 效果：替换/新增物品基底词缀为目标基底（与 ember 随机不同，玩家指定）
- 失败码：AFFIX_NOT_FOUND（目标非基底池）

## 3. 精华规格（6 种，定向保证词缀族出现）

| essence code | 名称 | 极性 | 目标族 | 对应词缀 |
| --- | --- | --- | --- | --- |
| ess_atk | 锋锐精华 | prefix | aff_atk | 锋锐 |
| ess_spirit | 蕴灵精华 | prefix | aff_spirit | 蕴灵 |
| ess_def | 御土精华 | prefix | aff_def | 御土 |
| ess_hp | 太一精华 | prefix | aff_hp | 太一 |
| ess_regen | 回春精华 | suffix | aff_regen | 回春 |
| ess_lingyun | 悟性精华 | suffix | aff_lingyun | 悟性 |

- 存储：game_essences（定义）+ game_essence_inventory（持有计数，单阶）；dev 注入 essence/grant
- 操作：op=essence + essenceCode；效果 = 混沌式重 roll（品阶与条数规则同 chaos），强制目标极性侧包含目标族 1 条（该族池内权重抽取 tier）；目标族不在底材该极性池 → NOT_AVAILABLE
- 消耗：1 枚对应精华（inventory count−1，同事务原子）

## 4. 数据变更

- 表：game_essences / game_essence_inventory（DDL + schema.prisma + init 重灌定义、保留存量）
- 种子：essences.json（6 条，显式 id）
- ItemAffixService 公开辅助：queryRollPool / samplePoolRows / rollOneFromRows（供定向 roll 复用）
- craft op 枚举 += wisp / essence；craft 签名加 extraCode

## 5. 冒烟清单

1. 图鉴 GET /essences 6 种；essence/grant 注入
2. wisp：指定 targetCode 替换基底；非法 code → AFFIX_NOT_FOUND
3. essence 定向：force 目标族必现；多次断言存在；悟性精华配 weapon 底材（该极性池无 aff_lingyun）→ NOT_AVAILABLE
4. 品阶/条数规则同 chaos；精华不足 → NOT_ENOUGH_ESSENCE
5. 回归：瓦尔/传奇/非 bag 拦截；health 200
