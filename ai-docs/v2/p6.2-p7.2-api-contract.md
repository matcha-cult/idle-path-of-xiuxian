# P6.2 / P7.2 API 契约 — 演出编排（计数无对外接口）

> 通用：JWT；响应 { success, message, data }；错误 data.code（HTTP 200 风格）
> 事件计数（kill_total/kill_unit/breakthrough_total/craft_total）通过任务目标消费，不单独开接口。

## 1. GET /api/game/story/chapter/:chapter

`:chapter` 为章节序号（1~5）或 code。

```json
{ "success": true, "message": "获取章节剧本成功",
  "data": { "chapter": { "code": "chapter_1", "name": "初入仙途", "chapter": 1 },
    "nodes": [
      { "nodeKey": "chapter:chapter_1:intro", "type": "chapter_intro", "text": "……", "seen": false },
      { "nodeKey": "quest:q_ch1_1:start", "type": "quest_start", "questCode": "q_ch1_1",
        "text": "……", "questStatus": "completed", "seen": false },
      { "nodeKey": "quest:q_ch1_1:done", "type": "quest_done", "questCode": "q_ch1_1",
        "text": "……", "questStatus": "completed", "seen": true },
      { "nodeKey": "chapter:chapter_1:outro", "type": "chapter_outro", "text": "……", "seen": false } ] } }
```

`type` ∈ chapter_intro / chapter_outro / quest_start / quest_done；无对应文本的节点不返回。
失败码：`CHAPTER_NOT_FOUND`。

## 2. GET /api/game/story/quest/:code

```json
{ "success": true, "data": { "quest": { "code": "q_ch1_1", "name": "初入仙途", "status": "completed" },
  "nodes": [ { "nodeKey": "quest:q_ch1_1:start", "type": "quest_start", "text": "……", "seen": false } ] } }
```

失败码：`QUEST_NOT_FOUND`。

## 3. POST /api/game/story/seen

请求 `{ "nodeKey": "quest:q_ch1_1:start" }`；非空字符串，最长 120。幂等（重复标记不报错）。

```json
{ "success": true, "message": "已标记已读", "data": { "nodeKey": "quest:q_ch1_1:start", "seen": true } }
```

失败码：`INVALID_PARAM`（nodeKey 缺失/超长）。
