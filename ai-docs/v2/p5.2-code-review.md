## 2. 关键正确性核对

- **链式解锁**：realm4 时 zone_miwu `unlockedReason=prev`（required 5 / prevBest 0）；enter 与 challenge 均返回 ZONE_LOCKED；打通 qingyun F1–F5（best=5）后解锁为 `ok`，enter 成功。
- **层深度派生**（确定性，实测）：F6 → tierOffset=1、extraDraws=1；F10（Boss）→ tierOffset=1、extraDraws=3+2=5；F20（Boss）→ tierOffset=3、extraDraws=6+2=8，且挑战响应同值。
