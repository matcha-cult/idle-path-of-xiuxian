## 1. 背景与目标

当前项目「放置·修仙之路」为 ionet-ts + NestJS 官方示例，已具备用户系统（注册/登录/JWT）与角色系统（nickname/gender/title/灵石/银两）。

本轮决定（已确认）：

1. **交付形态**：设计文档先行，评审通过后再进入实现。
2. **优先子系统**：物品与词缀（装备/法器、稀有度、前后缀铭文、功法联动）。
3. **放置核心循环**：自动刷宝 + 装备筛选自动拾取 + 离线收益。

目标：把 PoE 的"打宝（loot）→ 鉴定/洗装备 → 变强 → 打更难的图"循环，修仙风格化为

> 自动刷秘境夺宝 → 辨宝/祭炼法器 → 修为精进 → 闯更高层秘境

**设计基调（用户评审确认）**：

- **完全修仙风格化改造**：不照抄 PoE 的文案/数值/美术，借鉴的是其**设计理念**本身。
- **核心设计理念（按用户强调程度排序）**：
  1. 物品驱动成长（装备/铭文/灵阶）；
  2. **功法体系：心法 + 术法联动**（对应 PoE 主动技能/光环：9 功法槽 = 4 心法（1 主 3 辅）+ 5 术法；所有功法皆可修习且无法遗忘，最多装备 9 个，见 4.5 与 P2）；
  3. **灵石为基本交易货币**（金币位），13 种天材地宝工艺通货承担洗炼强化（见 4.6 与 P3）；
  4. 主线 **5 章剧情**，终章后离开当前世界进入**混沌**（设定参考《择日飞升》），以**混沌争夺战**为终局玩法（对应 PoE 异界图鉴争霸，见 4.11 与 P6）。
- **升华道统（Ascendancy）暂缓**：暂无想法，不强行映射。

## 2. 约束（沿用项目既有约定）

- 技术形态以 ionet-ts + NestJS + PostgreSQL（Prisma）为准。

> 注：品阶为物品固有属性，与当前词条数**解耦**——剥离铭文不降品阶（实测 PoE 行为，详见 4.6 词条数与品阶规则）。

### 4.3 词缀：铭文（Modifier）

- 统称**铭文**；前缀→**阳铭**（先天所铭），后缀→**阴铭**（后天禁制）。
- 每个铭文有：名称、阶数（tier）、所需灵阶（词缀池解锁条件）、属性效果、权重、适用类别标签。
- 示例：
  - 阳铭·锋锐（+攻击）、阳铭·蕴灵（+灵力上限）、阳铭·御土（+防御）
  - 阴铭·迅疾（+身法/攻速）、阴铭·回春（+生命回复）、阴铭·悟性（+灵韵获取）
- **天定铭文**（破裂词缀）：**神圣石/重铸石/剥离石/腐化（瓦尔宝珠）均无法修改或移除**，锁定词条永久保留；可由**破溃宝珠**分裂产生（见 4.6）。
- **基底铭文**（对应 PoE 隐含词缀 implicit，polarity=base）：基底自带的固定铭文槽，独立于阳铭/阴铭（例：某类剑基底自带「火灵加持：火系伤害 +10%」）；可为空，**古灵余烬/古灵溶液**可新增或替换（替换后原基底铭文消失，见 4.6）。
- 词缀池按「灵阶」解锁：秘境层数越高掉落的物品灵阶越高，可roll出的铭文阶数越高。

### 4.4 物品等级与灵阶

- PoE item level → 修仙**灵阶**（器物阶位，1~9 阶）。
- 灵阶决定：可出现的铭文池与装备强度；装备插槽已取消（见 4.5，改为角色固定功法槽）。
- 装备需求：高灵阶器物需要对应**修为境界**才能驱使（低境界（1~3 境）修士装备低阶法器，高境界方可驱动高阶灵宝；境界序号与映射见 4.8）。

### 4.5 功法与技能槽位（心法/术法，参考 PoE2）

**设计变更（设定修改 2/3/5/6）**：参考 PoE2（[poe2db.tw/cn/Gem](https://poe2db.tw/cn/Gem)）**取消装备插槽**，改为**角色固定功法槽**；并**取消辅助孔/6 连**，辅助结构并入心法主辅体系；设定修改 6 补充**道基流派与神识预算**取舍层（见下）。

- **9 个功法槽（最初即拥有）**：**4 心法槽 + 5 术法槽**，槽位固定为 9 个。
- **功法体系**：
  - **心法**（内功/光环类，对应 PoE 光环与常驻增益）：4 个心法槽整体为 **1 主 + 3 辅**——1 个**主心法**（定义道基）+ 3 个**辅心法**（额外光环/增益）；**无辅助孔**；
  - **术法**（招式/法术类主动技能）：5 个术法槽，**无主副、无辅助孔**，各自独立生效。
- **外功/内功（设定修改 2 保留）**：心法均属内功（炼气/炼神）；术法按 `school` 分**外功**（剑诀/刀法/拳掌/身法）与**内功系术法**（法术/御气）。
- **道基流派（设定修改 6）**：每个功法带 `daoji` 道基标签（剑/雷/火/冰/体/阵/丹/符…）。**主心法定义角色道基流派**：与主心法道基一致的术法获得协同加成（如伤害/效率提升），不一致的仅按基础生效——**换主心法即换流派**，构筑围绕流派展开。
- **神识预算（设定修改 6）**：3 个辅心法共享**神识预算**（每个心法带 `spirit_cost` 神识占用，强心法占用高）。装 3 个强辅心法 = 预算吃满；降级辅心法可换取更灵活的术法/搭配——形成「强度 vs 灵活」的真实取舍（对应 PoE 光环保留）。
- **槽位即激活**：只有放入功法槽的功法才处于**激活状态**；功法册中其余功法未激活（可随时换装，换下即失活）。
- **修习与装备分离（设定修改 3）**：**所有功法皆可修习（学习），且无法遗忘**；区别仅在装备数量——**最多同时装备 9 个（4 心法 + 5 术法）**。
  - **修习**：消耗功法玉简（或未开光玉简转化后）将功法**永久收入功法册**（不可遗忘）；
  - **装备**：从功法册选 9 个放入功法槽（4 心法 + 5 术法，心法槽内由玩家指定 1 主 3 辅）。
- **未开光玉简**：掉落「未开光玉简」（未切割宝石），可转化为任意功法（心法/术法均不按道统锁定，仅按主题排序）。
- **功法等级**：功法玉简有等级，消耗**灵韵**进行「参悟」升级（灵韵为通用成长资源，替代传统经验值；怪物不掉功法经验，对齐 PoE2 宝石升级独立于角色等级的设定，详见 4.13 灵韵体系）。

### 4.6 货币与通货体系（设定修改 12 重构）

**双轨货币体系**：

- **灵石 = 基本交易货币（金币位）**：坊市/拍卖/NPC 交易均以灵石计价（参考其他游戏金币 / PoE2 金币定位）；注册赠送低保 10000 灵石沿用。
- **工艺通货（13 种天材地宝）**：承担洗炼/强化功能，**不承担交易计价**；原「无统一金币、上百种通货作一般等价物」设计废弃（设定修改 12 修订）。

**工艺通货清单（用户定稿名，P3 落地时细化数值）**：

| 通货 | PoE 原型 | 效果 |
| --- | --- | --- |
| 混沌石 | Chaos Orb（**含改造石 Alteration 功能**） | **重roll当前品阶可有的词条数与铭文**：灵品 1~2 条、宝品 3~6 条（对灵品重roll即承担改造石职责，对宝品即混沌石本职） |
| 剥离石 | Annulment Orb | 移除 1 条随机铭文；**品阶不变**——可逐条剥离至 0 条铭文，宝品仍是宝品、灵品仍是灵品（实测 PoE：稀有 6 条全剥离后仍为稀有） |
| 重铸石 | Orb of Scouring | 清除全部铭文，**还原为凡品**（0 条铭文，基础属性保留）；灵品/宝品可用，传奇不可用；**无法清除天定铭文**（锁定词缀保留，其余词缀照常清除） |
| 点金石 | Orb of Alchemy | 凡品→宝品（roll 3~6 条铭文） |
| 蜕变石 | Orb of Transmutation | 凡品→灵品（roll 1~2 条铭文） |
| 崇高石 | Exalted Orb（**含富豪石 Regal 功能**） | **新增 1 条铭文**（仅灵品及以上可用）；灵品已满 2 条时再使用即升为宝品（继承富豪石升阶职责） |
| 神圣石 | Divine Orb | 重roll铭文数值（不改词条数与铭文种类） |
| 祝福石 | Blessed Orb | 重roll基础属性数值 |
| 映道镜 | Mirror of Kalandra（卡兰德的魔镜，修仙化改名） | 复制一件物品（镜像不可再复制） |

| 古灵溶液 | Wisp of the Allflame | **新增/修改基底铭文**（会替换原有基底铭文；2 种之二，**无品阶**） |

**词条数与品阶规则（设定修改 12）**：

- 凡品 0 条 / 灵品 1~2 条 / 宝品 3~6 条——为各品阶的**词条数范围**（生成与洗炼时可 roll 到的条数，对应 4.2 阳铭+阴铭上限）；
- **品阶与词条数解耦**：稀有度是物品**固有属性**，不随词条数变化——宝品剥离至 0 条铭文仍是宝品（实测 PoE：稀有 6 条全剥离后仍为稀有）；词条数范围只约束「生成/洗炼能 roll 到多少条」；
- **混沌石**：重roll当前品阶范围内的词条数与铭文（灵品 1~2 条、宝品 3~6 条）；品阶不变；**对灵品重roll即包含改造石（Alteration）职责**——PoE 中改造石海量消耗于灵品洗炼，本作并入混沌石不单列；
- **崇高石**：新增 1 条铭文（仅灵品及以上可用）；灵品已具 2 条时再使用即升为宝品——**继承 PoE 富豪石（Regal）的升阶职责**，品阶升级是崇高石的明确效果，不按词条数自动重算品阶；
- **剥离石**：移除 1 条随机铭文；**品阶不变**——可逐条剥离至 0 条铭文，宝品仍是宝品、灵品仍是灵品（不会降为凡品；凡品无铭文可剥离）；
- **重铸石**：清除物品全部铭文并**还原为凡品**（0 条铭文，基础属性保留）；灵品/宝品可用，凡品与传奇不可用；**无法清除天定铭文**——锁定词缀永久保留，其余词缀照常清除；
- **破溃宝珠**：分裂 1 条随机词缀并锁定为天定铭文（仅限 ≥4 词缀的宝品）；锁定词缀无法被**神圣/重铸/剥离/腐化**修改或移除；**锁词是制作流程的一步**——在 ≥4 词缀时锁定 1 条随机词缀，围绕锁定词缀继续洗炼（4 条下限 = 最早可锁定的时机，并非「提高锁中概率」的博弈点）；若锁中坏词缀，该词缀永久保留、底子作废；**破溃宝珠本身极稀少、价值极高**（顶级工艺通货地位）；
- **品阶只升不降（重铸石除外）**：点金/蜕变/崇高 升品阶；混沌石/剥离石不改变品阶；**重铸石是唯一将品阶重置回凡品的途径**（传奇固定铭文不可洗炼）。

**其他说明**：

- 原「100+ 种通货」规划废弃，精简为**灵石 + 13 种工艺通货**；炼丹/炼器材料、命格签等兑换凭证降为普通道具，不承担货币职能；
- **富豪石（Regal）不单列**：其「灵品升宝品」职责已并入崇高石（灵品满 2 条 +1 即升宝品）；富豪石功能太单一、用处太少，单独成通货价值低；
- **改造石（Alteration）不单列**：其「灵品重roll」职责已并入混沌石（混沌石对灵品重roll 1~2 条即改造石作用）；改造石虽在 PoE 做装时海量消耗，但功能与混沌石重叠、单列价值低；
- **机会石已删除（设定修改 13）**：凡品→传奇不再有通货途径（PoE 机会石为赌博性质，用途单一）；传奇仅靠掉落产出（及瓦尔宝珠变异的不确定结果）；
- **破溃宝珠设计意图（用户设定）**：锁词机制的目的 = **增加玩家制作顶级装备的成本**，让**极少数**装备有资格被**映道镜**（魔镜）复制——顶级装备必须稀缺；成本由两个杠杆维持：**① 随机赌注**——锁词是随机 N 选 1（≥4 词缀，如 4 选 1），赌错则底子作废；**② 破溃宝珠本身极稀少、价值极高**；
- **门槛降低但成本守恒（用户设定）**：锁词确实**降低了制作目标组合的门槛**（把 1 条目标词缀固化，其余围绕它洗炼）；但**随机赌注 + 破溃宝珠稀有度**使整体成本不降，且**词缀池权重**仍保证其余词缀极难 roll 出（PoE 实际中有些组合并不能很容易 roll 出来）——稀缺性由「词缀池权重 + 赌注 + 通货稀有度」共同维持；
- **制作流程示例（用户提供，PoE 脊弓）**：先「赌」破溃锁词——在 ≥4 词缀底子上随机锁中「弓类攻击发射 2 支额外箭矢」（破碎的·繁多之 = 天定铭文），再使用**精华**（PoE Essence，需实装，见下条）roll 后缀暴击（手术之），辅以大师工艺（工艺之·攻速）与品质强化——锁定词缀永久保留，其余词缀围绕它洗炼；
- **精华（Essence）需实装（用户设定，设定修改 14 细化）**：精华是**独立的工艺物品类别**，**非一般可堆叠通货**——区别于 13 种堆叠工艺通货，单件使用；效果 = **定向保证词缀类别**（如「该装备附加 X 基础火焰伤害」这类指定类型的前缀/后缀），对应 PoE Essence；
  - **掉落**：**怪物基础掉落**（普通怪物即出，非专属掉落源）；
  - **命名与分阶**（沿用 PoE 精华体系，修仙化命名 P3 出清单）：阶位 1~7，阶名 = 低语/呢喃/啼泣/哀嚎/咆哮/尖啸/破空；命名 = 「类型之阶名精华」（如 憎恨之低语精华）；
  - **普通精华（16 种，4 组）**：憎恨/悲痛/贪婪/轻视（1~7 阶）、哀惜/愤怒/折磨/恐惧（2~7 阶）、苦难/肆虐/雷霆/疑惑（3~7 阶）、煎熬/厌恶/刻毒/热情（4~7 阶）；
  - **稀有精华（4 种）**：凄惨/忌惮/傲视/忌妒，仅 **5~7 阶**；
  - **最稀有精华（4 种）**：浮夸/错乱/极恐/谵妄，**仅 1 阶**（特殊精华，不参与常规升阶）；
  - **升阶 = 3 合 1**：3 个同类型低阶精华合成 1 个高一阶精华；
- 原品质通货（淬火石/玄铁母矿/灵火砂）与定向工艺通货（灵髓油/上古化石/炼器炉芯/催化仙草）不在保留清单——品质提升（0~20）与定向工艺功能保留，改由炼器炉消耗普通炼器材料完成（P3 细化，待确认）；
- 功法侧（对应 PoE2 宝石等级/品质）：功法参悟升级消耗灵韵（见 4.13）；心法主辅重铸消耗通货/材料，属 P3 阶段。
- **现有角色表 spirit_stones / silver 的处理（设定修改 12 修订设定修改 9）**：
  - `spirit_stones`（灵石）：**基本交易货币（金币位）**——坊市/拍卖/NPC 交易计价单位，注册赠送低保 10000 灵石沿用；不承担工艺功能；
  - `silver`（银两）：弃用（灵石上位后不再需要）。

### 4.7 掉落与放置循环（自动刷宝 + 离线收益）

核心循环：

```
进入秘境(关卡) → 自动战斗结算 → 按掉落表产出物品
→ 辨宝法阵(拾取规则)筛选 → 符合规则→入储物袋(背包) / 不符→自动分解或弃置
→ 离线期间按效率继续结算 → 上线整理装备、祭炼强化 → 挑战更高层秘境
```

- **掉落表**：按「秘境关卡 × 物品基底 × 稀有度」配置权重；物品等级/灵阶随关卡提升；**灵韵**为基础掉落资源，随关卡灵阶递增（低级副本仍可产出灵韵、无递减惩罚，详见 4.13）。
- **拾取规则**（辨宝法阵，即 loot filter）：按稀有度下限、灵阶下限、目标铭文等筛选；动作可为保留/分解/出售（出售以灵石计价）。
- **离线收益（设定修改 10）**：`min(离线小时, 12) × 每小时轮数 × 60% 效率`；**12 小时封顶内不衰减**（原 8h 衰减阈值放宽至 12h，与封顶一致，实际不触发衰减）；日产出上限 200 件；超 12h 不再累积（已结算部分不清零）。

- **玩家最多 14 境**：玩家只允许「人和」式合道——合道**自身的小天地**，即**内演天地、合道自己的道**；不追求合道外物（天时/地利），因此永远无法触及 15、16 境。

### 4.13 灵韵体系（设定来源《黑神话·悟空》）

灵韵替代传统经验值体系，是修仙之路的核心成长资源。设定来源《黑神话·悟空》——灵韵为天地间散逸的灵气精华，修士击杀妖兽/魔头后可汲取其灵韵，用于自身修为精进与功法参悟。

**核心规则**：

- **灵韵获取**：击杀秘境中的妖兽/魔头/Boss 产出灵韵，为基础掉落资源（与物品掉落并存，互不挤占）。灵韵获取量受铭文「灵韵获取」加成（见 4.9 效果字段）。
- **无获取惩罚**：灵韵获取后永久持有，**死亡/失败不损失灵韵**（与《黑神话·悟空》一致——灵韵不会因死亡掉落）；突破失败消耗的灵韵不返还，但无额外惩罚（见 4.8 突破机制）。
- **灵韵用途**：
  1. **功法参悟**（技能升阶）：消耗灵韵提升功法玉简等级（对应 4.5 功法等级体系）；
  2. **境界突破**：消耗灵韵尝试突破修为境界（对应 4.8 境界体系）。
- **副本产出合理设定**：灵韵产出按秘境灵阶递增——低级副本产出稳定但效率低，高级副本产出丰厚但挑战难度高。低级副本灵韵产出**无递减惩罚**，玩家可无限伐木低级副本积累灵韵（效率低于高级副本，但胜在安全稳定）。玩家可自由选择「安全伐木低级副本」或「挑战高风险高级副本」的策略，二者均为有效成长路径。
- **与灵石的区别**：灵韵为角色绑定成长资源（不可交易），灵石为通用交易货币（可交易，见 4.6）；二者获取途径独立，互不干扰。

## 5. 数据模型设计（Prisma）

沿用现有 snake_case 命名与 `@db.Timestamp(6)` 风格。数据库形态见待审批项 2；以下表按独立 `game_` 前缀设计，与用户系统表不冲突。

```prisma
// ===== 物品基底（装备模板，含基础属性；功法类含外功/内功体系）=====
model game_item_bases {
  id           Int      @id @default(autoincrement())
  code         String   @unique @db.VarChar(50)   // 唯一标识，如 jian_qingfeng_1
  name         String   @db.VarChar(50)           // 「青锋剑」
  category     String   @db.VarChar(30)           // weapon/body/helmet/gloves/boots/shield/ring/amulet/belt/flask/jewel/currency/skill_gem
  slot         String?  @db.VarChar(20)           // 装备槽位（功法类为 null）
  sub_type     String?  @db.VarChar(30)           // 单手剑/双手剑/道袍/内甲…
  gem_type     String?  @db.VarChar(10)           // 功法大类：xinfa=心法 / shufa=术法（仅 skill_gem 类）
  school       String?  @db.VarChar(10)           // 功法体系：wai=外功 / nei=内功（仅 skill_gem 类；心法恒为 nei）
  daoji        String?  @db.VarChar(20)           // 道基流派标签（剑/雷/火/冰/体/阵/丹/符…，功法类；主心法定义流派，见 4.5）
  spirit_cost  Int?     @db.SmallInt              // 神识占用（仅心法；辅心法共享神识预算，见 4.5）
  spirit_grade Int      @default(1)               // 灵阶 1~9（对应 PoE item level）
  min_realm    Int?     @db.SmallInt              // 最低修为境界需求（境界序号 1~14，玩家侧封顶）
  base_stats   Json?                              // 基础属性模板 {"atk": 10, "def": 5}
  implicit_affixes Json?                          // 基底铭文模板（对应 PoE 隐含词缀，可空；古灵余烬/古灵溶液 新增/替换对象，见 4.3/4.6）
  unique_affixes Json?                            // 传奇（Unique）固定铭文 code 列表
  rarity_limit Int      @default(3)               // 可达最高稀有度 0凡/1灵/2宝/3传奇
  drop_weight  Int      @default(1)               // 掉落权重
  icon         String?  @db.VarChar(100)
  created_at   DateTime @default(now()) @db.Timestamp(6)
  updated_at   DateTime @updatedAt @db.Timestamp(6)
}

// ===== 铭文词缀（词缀池）=====
model game_affixes {
  id           Int      @id @default(autoincrement())
  code         String   @unique @db.VarChar(50)
  name         String   @db.VarChar(50)           // 「阳铭·锋锐」「阴铭·迅疾」
  polarity     String   @db.VarChar(10)           // yang=阳铭(前缀) / yin=阴铭(后缀) / base=基底铭文
  tier         Int      @default(1)               // 词缀阶数
  spirit_grade Int      @default(1)               // 解锁所需灵阶
  effects      Json                               // 属性效果 {"atk": 8}
  weight       Int      @default(100)             // 生成权重
  tags         String?  @db.VarChar(100)          // 适用类别标签（如 weapon, body）
  is_fractured Boolean  @default(false)           // 天定铭文（破裂词缀，洗炼不受影响）
  created_at   DateTime @default(now()) @db.Timestamp(6)
  updated_at   DateTime @updatedAt @db.Timestamp(6)
}

// ===== 具体物品实例 =====
model game_items {
  id            BigInt   @id @default(autoincrement())
  character_id  Int?                              // 归属角色；null=储物袋/未认领
  base_id       Int
  rarity        Int      @default(0)              // 0凡/1灵/2宝/3传奇
  item_level    Int      @default(1)              // 掉落时物品等级
  spirit_grade  Int      @default(1)
  quality       Int      @default(0)              // 品质 0~20
  affixes       Json?                             // [{affixId, value}]（规范化关联表见待审批项 3）
  status        String   @default("bag")          // bag/equipped/warehouse/selling
  created_at    DateTime @default(now()) @db.Timestamp(6)
  updated_at    DateTime @updatedAt @db.Timestamp(6)

  @@index([character_id, status])
}

// ===== 装备栏（角色当前穿戴）=====
model game_equipment {
  id           Int      @id @default(autoincrement())
  character_id Int      @unique
  slots        Json                             // {"weapon": 1, "body": 2, "ring1": 3, …} → game_items.id
  updated_at   DateTime @updatedAt @db.Timestamp(6)
}

// ===== 角色功法面板（固定 9 槽：4 心法 + 5 术法）=====
model game_skill_panels {
  id           Int      @id @default(autoincrement())
  character_id Int      @unique
  slots        Json     // {"xinfa": {"main": "code", "aux": ["code","code","code"]}, "shufa": ["code","code","code","code","code"]}
  updated_at   DateTime @updatedAt @db.Timestamp(6)
}

// ===== 功法册（已修习功法，永久不可遗忘）=====
model game_learned_skills {
  id           Int      @id @default(autoincrement())
  character_id Int
  gem_code     String   @db.VarChar(50)   // 功法（心法/术法）基底 code
  gem_type     String   @db.VarChar(10)   // xinfa=心法 / shufa=术法
  level        Int      @default(1)       // 功法等级（参悟升级）
  learned_at   DateTime @default(now()) @db.Timestamp(6)

  @@unique([character_id, gem_code])
  @@index([character_id])
}

// ===== 辨宝法阵（拾取规则 / loot filter）=====
model game_pickup_rules {
  id            Int      @id @default(autoincrement())
  character_id  Int
  name          String   @db.VarChar(50)
  rarity_min    Int      @default(0)            // 稀有度下限
  item_level_min Int     @default(0)            // 灵阶下限
  affix_codes   Json?                           // 目标铭文 code 列表
  action        String   @default("keep")       // keep / salvage(分解) / discard
  enabled       Boolean  @default(true)
  priority      Int      @default(100)
  created_at    DateTime @default(now()) @db.Timestamp(6)
  updated_at    DateTime @updatedAt @db.Timestamp(6)

  @@index([character_id])
}

// ===== 掉落表（自动刷宝产出配置）=====
model game_drop_tables {
  id         Int      @id @default(autoincrement())
  zone_id    Int?                               // 秘境关卡 id（秘境系统落地后关联）
  base_id    Int
  rarity     Int      @default(0)
  weight     Int      @default(1)
  min_level  Int      @default(1)
  max_level  Int      @default(1)
  created_at DateTime @default(now()) @db.Timestamp(6)

  @@index([zone_id])
}
```
