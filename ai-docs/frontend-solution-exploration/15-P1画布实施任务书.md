## 5. T4 · 生成器落格 + 自检（`packages/server/scripts/gen-map-seed.mjs`）

### 5.1 落格算法（确定性，参照 `tmp/map-layout.mjs`）

1. **极坐标初值**（半径与角度按 `n` 成比例）：
   - `summit` → 半径 0；
   - `peaks` → 半径 `n/2 - 1`，角度由 `sector`（八方位）；
   - `outer` → 半径 `n/2`，角度由 `sector`（四正方位）；
   - `approach` → 半径 `(peaksR+gatesR)/2`，角度 252°；
   - `inner` → 四层同心弧（内环一最外 … 内环四最内），弧长恒定（每节点 `arc` 格）⇒ 半径越小张角越大。
2. **落格顺序**：`summit → peaks → inner → approach → outer`
   （八峰是环的骨架，**必须先落**，否则会被挤离方位）。
3. **吸附**：对每个节点，在 `0..n` 的交叉点中选「离理想位最近且合法」的一个。
4. **合法性**：与已落点切比雪夫距离 `≥ 1`；`< sep` 时**仅当两者有边才允许**（相邻可近）。
5. **参数**：`n=21`、`sep=2`、`arc≈2.4`。

### 5.2 自检（**硬失败**）

| 检查 | 说明 |
| --- | --- |
| 坐标在 `0..rows` / `0..cols` 内 | 越界 = 画到画布外 |
| 同图无撞点 | DB 唯一约束的前置兜底 |
| 每节点都有坐标 | 漏格 = 图上有洞 |
| **落点最大偏移 ≤ 2.5 格** | 相对极坐标理想位；`sep` 贪大就会崩形状 |
| 前置引用不悬空 | 现有检查保留 |
| 连通性 | 现有检查保留 |
| 秘境数 ≤ 1、无 `idle_spot`、level ≤ 图上限 | 现有检查保留 |

**软提示（只打印，不失败）**：边跨度直方图、**不相邻最小间距**、**连线交叉数**。

### 6.1 ui-kit `packages/ui-kit/src/layout/GraphCanvas/`（**零业务**）


```ts
export interface GraphCanvasItem { key: string; row: number; col: number; content: ReactNode;
                                   onSelect?: () => void; selected?: boolean; disabled?: boolean; title?: string }
export interface GraphCanvasLink { from: string; to: string; state?: 'normal' | 'active' | 'locked' }
export interface GraphCanvasProps {
  rows: number; cols: number;
  items: readonly GraphCanvasItem[];
  links?: readonly GraphCanvasLink[];
  cellPx?: number;              // 缺省 48
  showGrid?: boolean;           // 缺省 false
  onBackgroundClick?: () => void;
  ariaLabel?: string;
}
```

要求：
- 底图/连线/网格层 **跟随 zoom**；**枢纽层不跟随**（`left = col*cellPx*zoom + panX`），
  图标恒定屏幕尺寸、热区不随 zoom 变；
- 默认 `zoom_fit` 整图适配；`Ctrl/⌘ + 滚轮`缩放，普通滚轮**不劫持**页面滚动；
- 拖动平移；**pointer 位移 > 8px 视为拖动，不触发 `onSelect`**；
- `showGrid` 时渲染**交叉点点阵 + 轴标 `0..cols/rows` + 每个 item 的 `(row,col)`**；
- 颜色只用 `theme.useToken()`（**禁 hex**）；不 import `@idle-path/*` / `mobx` / `node:*`；
  一文件一组件、禁 `export default`、≤200 行、必须有同目录单测。
- 边界单测：`rows/cols ≤ 0`、`items` 空、坐标越界、`links` 指向不存在 key、重复 key、
  `links=[]` 单点无边、`cellPx` 非法（0/负/NaN）、`zoom` 夹取。
