## §A 共用规则（每个子代理都必须遵守）

### A.1 必读顺序（别跳）

1. `11-面板重做进度与接续手册.md` §2 标准步骤 / §3 store API 速查 / §4 已锁定约定 / §6 已知坑；
2. `10-玩法驱动的面板设计.md` §0 核心玩法总览 + **你负责域的 §1.x**（玩家目标 / 关键数值 /
   动作清单 / 建议界面结构 / **必须隐藏的字段**）；
3. 参考实现：`packages/web/src/pages/game/panels/ZonePanel.tsx` + `panels/zone/`（子组件拆分范式）；
   更贴近本批的样板：`panels/RealmPanel.tsx`、`panels/IdlePanel.tsx`（均 ≤200 行、含 store 交互）。

### A.2 允许写的文件（其它一律不许碰）

- `packages/web/src/pages/game/panels/<Name>Panel.tsx`（覆盖旧版）
- `packages/web/src/pages/game/panels/<Name>Panel.test.tsx`（覆盖旧版测试）
- 若单文件超 200 行：允许新建 `packages/web/src/pages/game/panels/<name>/` 子目录放
  子组件 / 纯函数（+ 同目录测试），照 `panels/zone/` 的做法。

**禁止碰**：`panel-registry.tsx`、`GameShellPage.*`、`packages/ui-kit/src/index.ts`、
任何 `*.config.ts` / `vite.config.ts`、任何 store、任何其它包。
翻牌与删旧文件由主线做——你在回报里写清「请主线翻牌 `<key>`」即可。

### A.3 硬约束（违反会被 hygiene 门禁或评审打回）

- 容器面板：`observer(...)` + `useRootStore()`；**挂载时不拉取数据**
  （首屏由 `RootStore.loadPanel()` 并发加载，已覆盖 item/equip/skill/economy/realm/quest/zone/idle/story/combat）；
  三态一律交给 `AsyncBoundary`。
- 结构按「问题驱动三段式」（zone 样板）：**现在什么情况 → 能做什么 → 做完得到什么**。
- **协议字段不上屏**：`code` 只做 key/testid、`orderIndex` 只排序、`unitCode`/`bossCode` 不展示；
  数值用 `formatCompactNumber` / `formatDuration`（`src/domain/format.ts`）。
- 破坏性 / 不可逆操作用 `ConfirmAction`。
- 只用 **antd 已有组件** + `@idle-path/ui-kit` 已导出组件（先读 props 再写）。
  本批可用的新增通用件：`AffixList` / `SlotBoard` / `CraftOpPicker` / `DropPoolTable` /
  `StoryTimeline` / `ItemPickerModal`，以及既有的 `PagedGrid` / `StatGrid` / `StatCompare` /
  `ResourceBar` / `ResourceGrid` / `KeyValueList` / `SettlementSummary` / `LockedHint` /
  `ItemCard` / `RarityTag` / `QuantityInput` / `ActionBar` / `EmptyHint` / `ActionForm`。
- 单文件 ≤200 行；颜色只用 antd token；禁内联 hex、`!important`、`<style>`、
  静态 `message.*` / `Modal.confirm`、`export default`、`size`（紧凑恒开）。
- 业务失败口径是 `data.success === false`：面板只消费 store 已有的 `error` / 业务码状态，
  **不要在面板里重判协议**，也不要新加 store 方法。真缺字段就写进回报，由主线补。

### A.4 测试要求（每个面板一个测试文件，≥5 例）

- 用 `packages/web/test/helpers/panel-harness.tsx` 的 `createPanelHarness()`；
  交互用例**必须先 `await harness.connect()`**。
- 必覆盖：正常渲染 / 空态 / loading+error / **交互真发出对应 `cmd/subCmd`**
  （常量从 `@idle-path/ionet-transport` 导入，**禁止字面量**）/ 边界（`null`、空数组、极值）/
  断言页面文本不含 DTO 字段名与 ISO 时间串。
- 已知断言坑：antd 会在两个中文字之间插空格（用 `/登\s*录/`）；图标 `aria-label` 会进可访问名
  （用 `/秘境/`）；`Drawer` 关闭后 children 仍挂载；seed 之后要 `act()`。

### A.5 验证命令（逐条跑，回报贴真实输出）

```bash
# 聚焦跑自己负责的面板（--maxWorkers/--minWorkers 必须加：4 个代理并行，
# 不加会互相抢满 CPU 导致 60s 超时假失败；不要去改任何 config 文件）
pnpm --filter idle-path-web exec vitest run src/pages/game/panels/<X>Panel.test.tsx --maxWorkers=2 --minWorkers=1
pnpm --filter idle-path-web exec vitest run src/pages/game/panels/<X>Panel.test.tsx src/pages/game/panels/<Y>Panel.test.tsx --maxWorkers=2 --minWorkers=1
pnpm --filter idle-path-web run typecheck
```

> 背景：`maxWorkers:'50%'` 配置坑已在 `3e3b27c` 修掉，现在**不加参数也能跑**；
> 上面加参数纯粹是为了 4 个代理并行时的 CPU 公平。
