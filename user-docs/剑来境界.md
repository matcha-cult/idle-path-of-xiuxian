在《剑来》的设定里，练气士的修行之路共分十六境，大致可以归为“下五境”、“中五境”、“上五境”和“失传二境/未知境”四个阶段。清晰的境界体系与名称正好通过表格整理如下（第十五境与第十六境，你也可以理解为“失传二境”）：

### **《剑来》练气士境界体系**

| 阶段 | 境界序号 | 境界名称 | 备注与简要描述 |
| :--- | :--- | :--- | :--- |
| **下五境**<br>（登山五境） | 第一境 | **铜皮** | 真气激发时，皮肤呈紫铜色，大成者可无视部分物理伤害。 |
| | 第二境 | **草根** | 喻意“斩草不除根，春风吹又生”，此境大成者拥有出众的血肉恢复能力。 |
| | 第三境 | **柳筋** | 经脉坚韧，真气运转愈发顺畅。曾有柳姓修士单凭炼筋直入上五境，此境因而得名。 |
| | 第四境 | **骨气** | 骨骼坚硬，骨气充盈，为后续修行打下坚实的内在基础。 |
| | 第五境 | **铸炉**<br>（或作筑庐） | 以肉身为炉鼎，能够储存和凝练更多真气。 |
| **中五境** | 第六境 | **洞府境** | 可在体内开辟洞府空间储存灵气，对灵气的掌控更加自如。 |
| | 第七境 | **观海境** | 体内真气如海洋般浩瀚，能更清晰地感知和吸纳天地灵气。 |
| | 第八境 | **龙门境** | 修行路上的关键门槛，取“鱼跃龙门”之意，突破后实力将大幅提升。 |
| | 第九境 | **金丹境** | 又称结丹境。一生仅三次结丹机会，失败则修为退回洞府境。 |
| | 第十境 | **元婴境** | 又称地仙。可在识海中养育出阳神或阴神，如同稚童居住，寿命长达数百年。 |
| **上五境**<br>（长生五境） | 第十一境 | **玉璞境** | 已达练气大成、返璞归真之境，肉身亦趋于圆满，多为一般宗门之主。 |
| | 第十二境 | **仙人境** | 已是大神通者，主角陈平安在故事中主要处于此境界。 |
| | 第十三境 | **飞升境** | 几乎天下无敌。但破境时会被天道察觉，视为天地大盗，为天地所不容。 |
| | 第十四境 | **合道境** | 将自身融入一方大道，大道不息，生命不止。合道方式有天时、地利、人和三种。 |
| **失传/未知境** | 第十五境 | **（暂称十五境）** | 具体名称未明确。书中设定仅道祖、至圣先师、佛祖三人达到此境。 |
| | 第十六境 | **（暂称十六境）** | 传说中的至高境界，已知仅有旧天庭共主（即那个“一”）踏入过此境。 |

> 第十六境是书中世界观的终极顶点，代表着修士所能追求的至高境界。
