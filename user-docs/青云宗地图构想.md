这个圆形同心环结构很顺，建议定名为：**“四门八峰·内环功能·中央主峰”**。  
即：最外环四山门护山大阵，第二环八峰（七职业峰 + 一历练秘境峰），第三环功能地点，最中心主峰。

## 四、内环功能地点

内环不单独对应职业，作为宗门公共功能逐步解锁：

```text
内环一：执事堂、内门广场、青云传送阵
内环二：藏书阁、戒律堂、传功崖
内环三：丹霞院、百器阁、灵兽苑、灵田药园
内环四：天刑台、禁地入口、护法下院
```

| 功能地点 | 作用 |
|---|---|
| 藏书阁 | 功法、残卷、悟道 |
| 戒律堂 | 执法、关禁闭、清除恶名 |
| 传功崖 | 技能突破、传功 |
| 丹霞院 | 炼丹、丹药 |
| 百器阁 | 炼器、法宝、装备打造 |
| 灵兽苑 | 御兽、坐骑、灵兽培养 |
| 灵田药园 | 灵草、药材采集 |
| 执事堂 | 宗门任务、贡献点 |
| 内门广场 | 公告、宗门事件、跑图枢纽 |
| 天刑台 | PVP、天刑试炼 |
| 青云传送阵 | 已点亮节点快速传送 |

## 五、中心主峰

```text
                 ┌──────────────┐
                 │   青云主峰   │
                 │  护法堂 ★    │
                 │  主峰之巅    │
                 │  七护法轮值  │
                 └──────────────┘
```

青云宗无掌教，主峰护法堂由七位护法长老轮值。七位护法可分别对应七座职业峰，后山峰由后山护法或轮值护法兼管。
